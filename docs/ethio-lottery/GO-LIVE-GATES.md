# Ethio Lottery — Go-Live Gates

Nothing in this checklist is considered complete merely because a draft document or UI exists.

- [ ] Owner decides to begin formal licensing and tax review.
- [ ] Ethiopian legal counsel confirms current legal classification and requirements.
- [ ] ELS / National Lottery Administration provides written own-operator eligibility and permit guidance.
- [ ] Legal entity, business licence, TIN and tax treatment are confirmed.
- [ ] Required raffle permit is issued and verified.
- [ ] ELS approves the technical and operational model in writing.
- [ ] CBE gives written approval for the exact licensed raffle use case.
- [ ] Telebirr gives written approval for the exact licensed raffle use case.
- [ ] M-PESA gives written approval for the exact licensed raffle use case.
- [ ] Prize reserve, statutory commission, tax, refunds and settlement are independently reviewed.
- [ ] Draw process is independently audited and approved.
- [ ] Security, KYC/age eligibility, privacy and responsible-gaming controls pass review.
- [ ] Production ticket, payment, draw and prize-ledger migrations are separately reviewed.
- [ ] API and app end-to-end tests pass in a provider sandbox.
- [ ] Owner explicitly approves the production release.

Until every applicable gate is evidenced and the owner authorises release, keep the service planned, private and disabled.
